📌 Descrição do ProblemaDada uma string s, retorne a substring palíndroma mais longa em s.Palíndromo: Uma palavra/sequência que se lê da mesma forma de trás para frente ou de frente para trás (ex: "aba", "racecar", "bb").💡 Algoritmo: Expansão a Partir do CentroUm palíndromo é espelhado em relação ao seu centro. Podemos iterar por cada caractere e tentar expandir para a esquerda e para a direita enquanto os caracteres forem iguais.Existem $2n - 1$ centros possíveis em uma string de tamanho $n$:Centros de tamanho ímpar ($n$ centros): O centro é um único caractere (ex: "aba", centro no 'b').Centros de tamanho par ($n - 1$ centros): O centro fica entre dois caracteres iguais (ex: "abba", centro entre os dois 'b').
